# ZMCENTR visual evidence

Public transport for synthetic ZMCENTR UI review screenshots only.

- No production, client, DIKIDI, financial, workbook, or payment-proof data.
- No application source, SQL, migrations, credentials, or sensitive logs.
- Review images are immutable PNG files addressed by their image commit SHA.
- Phase `latest.json` files are convenience pointers, never image authority.

The private ZMCENTR repository remains the canonical audit source. This public
repository exists only so visual reviewers can retrieve explicitly approved,
privacy-reviewed evidence without credentials.
